အသုံးပြုရန်
1. ZIP ကိုဖြည်ပြီး index.html ကိုဖွင့်ပါ။
2. Online ဖြင့် အသုံးပြုရန် HTTPS hosting (ဥပမာ GitHub Pages / Netlify) ပေါ်တင်ပါ။
3. Viber Booking သည် အချက်အလက်ကို clipboard သို့ကူးပြီး Viber chat ကိုဖွင့်ပေးသည်။ Viber ထဲတွင် Paste လုပ်ပြီး Send ကို ကိုယ်တိုင်နှိပ်ရပါမည်။ Booking အတည်ပြုချက်သည် ဝန်ဆောင်မှုပေးသူထံမှ ပြန်လည်ရရှိမှသာ အတည်ဖြစ်သည်။
4. ဓာတ်ပုံများပြရန် images/car-exterior.jpg, images/car-interior.jpg, images/car-cargo.jpg ဖိုင်များကို images ဖိုလ်ဒါထဲ ထည့်ပါ။
5. PWA install နှင့် offline cache သည် HTTPS hosting တွင် အလုပ်လုပ်သည်။

ထည့်သွင်းထားသော ပြင်ဆင်ချက်များ
- Desktop / Mobile navigation link များအားလုံးကို သက်ဆိုင်ရာ section သို့ချိတ်ဆက်ထားသည်။
- Booking သို့ တိုက်ရိုက်သွားနိုင်သော tab ထည့်ထားသည်။
- Theme toggle, Booking validation + clipboard fallback, Lightbox close, Back-to-top, active navigation နှင့် service worker ကို စီစဉ်ထားသည်။
